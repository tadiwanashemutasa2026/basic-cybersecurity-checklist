Basic Cybersecurity Checklist

1. Project Title

Basic Cybersecurity Checklist

 Purpose

The purpose of this project is to help students and computer users stay safe when using the internet. It explains simple ways to protect computers, personal information, and online accounts from cyber threats.

 Contents

This project covers the following topics

Creating strong passwords.

Using two-factor authentication.

Identifying fake emails and suspicious links.

Keeping software and antivirus protection updated.

Backing up important files.

Locking computers when not in use.

Reporting suspicious online activities.

 How to Use It

Students and computer users can use this checklist to check whether they are following basic cybersecurity rules. They should read each point and apply it when using computers, mobile phones, and the internet. The checklist can also be used as a reminder at school, home, or work.

 Security Advice

Always use strong passwords and never share them with other people. Do not click on suspicious links or download unknown files. Keep personal and confidential information private. Make sure your software is updated and report any suspicious activity to the IT department or the relevant support team.
